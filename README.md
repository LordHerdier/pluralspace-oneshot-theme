# pluralspace-oneshot-theme

An OneShot-inspired custom theme for pluralspace.app, used via its custom CSS setting.

## Usage

Requires a userstyle extension like [Stylus](https://github.com/openstyles/stylus) to inject custom CSS into a site. Paste the contents of `pluralspace-oneshot-theme.css` into a new style for pluralspace.app.

Assets live in `assets/` and are referenced from the CSS via raw.githubusercontent.com URLs.
